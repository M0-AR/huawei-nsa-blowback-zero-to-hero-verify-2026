🌱 Beginner guide — read this and you are a professional

Let's work this out in a step-by-step way to be sure we have the right answer.

  1. What is a router? A box that reads every message, splits it into tiny packets, decides where each goes, and forwards it. Your home box does this for one family; national boxes do it for ministries, banks and mobile networks.
  2. Why does the maker matter? The maker writes the code, fixes bugs remotely and ships updates. You hand them the keys to the road every message travels on. The only fix is trust plus verification.
  3. What is a backdoor? A hidden flaw only the maker (or whoever steals the key) knows. To you the box looks fine; to the key-holder every message is readable at any time.
  4. Why can't we just open and check? Millions of lines of code per device, millions of devices per country — and tomorrow's update can undo today's clean check. Auditing once does not mean safe forever.
  5. What is interdiction? Stopping a shipment on the way to the buyer, opening the box, installing hidden software, resealing it so nobody notices, and letting it continue to the buyer.
  6. What is a persistent implant? Software hidden where the box starts (boot memory) so it survives power cuts, reboots and even upgrades — like ink soaked into paper, not pencil on top.
  7. What did the independent audit find? A UK lab with full source code for ~10 years found no intentional backdoor — but messy code anyone skilled could exploit: unsafe memory copies, number errors, ignored warnings, builds that do not match audited source.
  8. What is blowback? A secret tool built for spying gets stolen and reused by everyone — including criminals. One leaked Windows tool became two global worms in weeks, costing billions and closing hospitals.
  9. What should you remember? Four numbers: 12/12 claims confirmed · $16B blowback · 28 days leak-to-worm · 1062/6985 CVEs. Say those with one example each and you sound professional.
  10. What next? Run docker compose up --build, open benchmarks/RESULTS.json, then try the Pro quiz level below.

❓ FAQ

Does this claim a specific device shipped with a backdoor?
No. It scores capability/readiness separately from deployment, and reports zero public proof of an intentional vendor backdoor after maximal access.

Why do CVE counts matter if they are not backdoors?
They measure attack surface. Poor hygiene is exploitable by anyone — which is why audit ≠ immunity and build integrity matters.

What if I am offline?
Committed snapshots let everything reproduce; live calls are flagged live:true/false.
